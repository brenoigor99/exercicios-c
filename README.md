# Exercícios de Lógica em Linguagem C 🚀

Este repositório contém meus primeiros exercícios desenvolvidos em C para a matéria de LP1

## 📁 Conteúdo do Repositório
Atualmente, o projeto conta com os seguintes programas:
* **Fatorial:** Cálculo do fatorial.
* **Conversor de Temperatura:** Conversão entre Celsius e Fahrenheit.
* **Verificador de Primos:** Lógica para identificar números primos.
* **Soma de Array:** Leitura de 5 números inteiros e cálculo da soma total.
* **Contador de Palavras:** Algoritmo que percorre strings para contar palavras.
